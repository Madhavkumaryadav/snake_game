# 🐍 Snake Game using Python and Tkinter

A classic Snake Game built using **Python** and the **Tkinter** GUI library. This project was created for learning purposes and to practice GUI development, game logic, and event handling in Python.

---

## 🎮 Game Features

- 🟨 Snake grows on eating food
- 🍎 Random food placement
- 💥 Collision detection (walls & self)
- 🎯 Real-time scoring
- 🕹️ Control using Arrow Keys or WASD
- 🖥️ Game over screen with final score

---

## 🧠 What I Learned

- GUI programming with `tkinter`
- Managing canvas and coordinate systems
- Implementing game loops using `after()`
- Handling keyboard events
- Object-oriented design in Python
